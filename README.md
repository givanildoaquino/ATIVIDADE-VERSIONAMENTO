# ATIVIDADE-VERSIONAMENTO

Atividade do SENAI sobre versionamento com Git e GitHub.

## Conceitos praticados

- `git init`, `git add` e `git commit`
- Criação de branches (`git checkout -b`)
- Merge e resolução de conflitos
- Envio para o GitHub (`git push`)

O exercício completo está em [meu-projeto-senai](https://github.com/givanildoaquino/meu-projeto-senai) e [senai-versoes-colaboracoes](https://github.com/givanildoaquino/senai-versoes-colaboracoes).
